# Data Setup

SandMLE training and evaluation use two kinds of tasks. Neither is committed to this repo;
set the paths in `.env` (copied from `.env.example`) and download as below.

## 1. Synthetic SandMLE tasks (training + synthetic eval)

The synthetic micro-scale MLE tasks generated by the SandMLE pipeline are hosted on Google Drive:

- https://drive.google.com/file/d/1qARX8hObQfLw3eXxpea79JOz2gjPAGmk/view?usp=sharing

Download and extract so that `SANDMLE_SYN_DATA_ROOT` contains one folder per task, each with:

```
<SANDMLE_SYN_DATA_ROOT>/<task_id>/prepared/public/
    description.md          # task prompt
    train.csv / test.csv / images|audio|docs ...   # public data
    sample_submission.csv
    evaluator.py            # deterministic scorer (used by SynScoreTool)
    answer.csv              # hidden ground truth (used by evaluator.py)
```

The bundle also includes the sanity-passed task id lists referenced by
`SANDMLE_OK_LIST` (`ok_competitions_sanity.json`) and `SANDMLE_OK_LIST_SAMPLED`
(`ok_competitions_sanity_random_64.json`). Point those env vars at the extracted files.

## 2. MLE-bench data (real-task evaluation)

MLE-bench competitions are Kaggle-derived and cannot be redistributed here. Download them with
the official `mlebench` tool (requires Kaggle credentials) into `SANDMLE_DATA_ROOT`:

```bash
pip install mlebench           # or install from https://github.com/openai/mle-bench
mlebench prepare -c aerial-cactus-identification --data-dir "$SANDMLE_DATA_ROOT"
# ... repeat for the competitions you want to evaluate (see the list in custom_evaluate.py)
```

`custom_evaluate.py --dataset easy` uses the fixed MLE-bench-lite competition id list;
`--dataset hard` uses every prepared competition except that list.

## 3. Build training/validation parquet

Once the synthetic tasks are in place:

```bash
python -m examples.deepresearch.prepare_train_data --synthetic
```

This registers `train.parquet` / `test.parquet` under `SANDMLE_DATASETS_DIR/mle_bench_syn`,
which the training scripts consume.
